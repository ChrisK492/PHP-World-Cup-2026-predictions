# PHP-World-Cup-2026-predictions
A PHP app where every user can guess the outcome of each match. Whoever guessed the best, wins

important:
im don't include database files. This github repository is pure code.

Features:
- a user can register and login to the app.
- You are presented with cards of each world cup phase. When a phase isn't active it gets locked.
- Each phase has matches the user can bet on. When the match date is over, the user can't predict anymore or change their predictions anymore


Point system per predicted match:
- When a user has predicted the outcome perfectly: 5 points
- When a user has predicted the right winner: 3 points
- When a user has predicted the outcome would be draw: 2 points
- None of these: 0 points

Users can see the current leaderboard by clicking on "uitslag". 

The database is massive. There are hundreds of matches, all with their own data. That was the most difficult part.
I really love how it turned out!!
